## Project Highlights

### Smoking Health Data
- 데이터 규모: 약 7,000건 / 18개 컬럼
- 주제: 흡연 여부와 BMI, 충치, 중성지방, 혈압 등 건강 지표의 관계 분석
- 결과 요약:
  - BMI 구간이 높아질수록 흡연자 비율이 증가하는 경향 확인
  - 흡연자 집단에서 충치 발생 비율이 더 높게 관찰됨
  - 흡연자 집단의 평균 중성지방 수치가 더 높게 나타남
  - 혈압은 큰 차이가 관찰되지 않음
